# INEXION (INX): основная сеть

Монета с собственной сетью: у людей свои **узлы** и **майнеры**, ключи хранятся **только у владельцев**,
каждый блок и каждый перевод проверяется каждым узлом по одним и тем же правилам. Здесь нет бирж, аккаунтов
и паролей: только блокчейн, кошелёк, майнер и обозреватель блоков. Только стандартная библиотека Python 3.8+,
ничего ставить не нужно.

| Файл | Что делает |
|---|---|
| `core.py` | Правила сети: подписи, блоки, награды, халвинг, заморозка основателя, сложность. **После запуска сети не менять** |
| `node.py` | Полный узел: проверяет цепочку, общается с другими узлами, мемпул, API, обозреватель блоков |
| `miner.py` | Майнер (все ядра процессора) |
| `wallet.py` | Кошелёк: ключ создаётся и остаётся у вас, перевод подписывается локально |
| `genesis.py` | Создаёт и проверяет первый блок |
| `explorer.html` | Обозреватель блоков (открывается на адресе узла) |
| `tests/` | Автотесты (правила сети, сеть из нескольких узлов, кошелёк, консольные программы) |

## Монета

* Лимит **21 000 000 INX**, 8 знаков после запятой, все суммы в сети целые числа.
* **10% (2 100 000 INX) основателю**: записаны в первом блоке на адрес основателя и **заморожены**: размораживаются
  линейно за 2 года. Это правило сети: узлы отвергнут перевод замороженной части, что бы ни делал владелец ключа.
* **90% (18 900 000 INX) только майнерам**: 4,5 INX за блок, награда делится пополам каждые 2 100 000 блоков (около 4 лет при блоке раз в минуту).
* Блок раз в ~60 секунд. Сложность пересчитывается каждые 144 блока (не больше чем в 4 раза за раз).
* Комиссия за перевод не меньше 0,00001 INX, достаётся майнеру.
* Подписи ECDSA secp256k1, proof-of-work двойной SHA-256. Подпись привязана к первому блоку сети: перевод из одной
  сети нельзя повторить в другой.

## Быстрый тест на одном компьютере (учебная сеть, монеты ничего не стоят)

Откройте Терминал в папке проекта. Каждая команда ниже: отдельное окно Терминала там, где указано.

```bash
# 1. Кошелёк. ЗАПИШИТЕ код восстановления на бумагу.
python3 wallet.py new --file wallet.json

# 2. Первый блок (bits 12 = очень лёгкая сложность, только для теста)
python3 genesis.py create --founder ВАШ_АДРЕС --message "test network" --bits 12 --out genesis.json

# 3. Узел (окно 1)
python3 node.py --genesis genesis.json --datadir data1 --port 9333

# 4. Майнер (окно 2); награда придёт на ваш адрес
python3 miner.py --node http://127.0.0.1:9333 --address ВАШ_АДРЕС

# 5. Обозреватель: откройте в браузере
#    http://127.0.0.1:9333
```

Второй узел на этом же компьютере (проверка, что сеть синхронизируется):

```bash
python3 node.py --genesis genesis.json --datadir data2 --port 9334 --peer http://127.0.0.1:9333 --allow-private
```

Перевод:

```bash
python3 wallet.py balance --node http://127.0.0.1:9333
python3 wallet.py send --to АДРЕС_ПОЛУЧАТЕЛЯ --amount 5 --node http://127.0.0.1:9333
```

## Запуск настоящей сети

1. **Создайте кошелёк основателя** (`wallet.py new`) на надёжном компьютере, лучше без постоянного доступа в
   интернет. Запишите код восстановления на бумагу, сделайте две копии, храните в разных местах. Если ключ украдут,
   вор получит всё, что уже разморожено. Если потеряете: доля пропадёт навсегда. **Восстановить её не сможет никто.**
2. **Создайте первый блок**:
   `python3 genesis.py create --founder АДРЕС --message "ваше сообщение" --bits 26 --time ВРЕМЯ_СТАРТА --out genesis.json`
   * `--time` (unix-время) в будущем задаёт момент старта: раньше чем за 2 часа до него блоки не принимаются, так сеть
     стартует для всех одновременно, а не для того, кто успел первым.
   * `--bits` начальная сложность. Слишком лёгкая даёт огромное преимущество самым быстрым в первые часы.
     Подберите под ожидаемую мощность майнеров и учтите: сложность подстраивается только раз в 144 блока.
3. **Опубликуйте `genesis.json` и его `chain_id`** (его печатает `genesis.py verify genesis.json`). Все узлы должны
   запускаться с **одним и тем же** файлом. После публикации менять его нельзя: получится другая сеть.
4. **Запустите первый узел на сервере**:
   `python3 node.py --genesis genesis.json --datadir data --host 0.0.0.0 --port 9333 --public-url http://ВАШ_IP:9333`
   (и откройте порт в файрволе). Другие узлы подключаются так: `--peer http://ВАШ_IP:9333`. Чтобы сеть не зависела от
   одного сервера, нужны несколько независимых узлов у разных людей.
5. **Обозреватель блоков**: тот же адрес узла в браузере. Для публичного доступа поставьте перед узлом веб-сервер
   (Caddy/nginx) с HTTPS.
6. Майнеры запускают `miner.py` с адресом своего кошелька, обычные пользователи используют `wallet.py`.

## Честно об ограничениях (прочтите до запуска)

Это полноценная рабочая реализация, но она **не проходила независимый аудит и публичный тестнет**.
Автотесты (`tests/`) проверяют правила сети, сеть из нескольких узлов, форки, откаты, кошелёк и консольные программы,
но тесты не заменяют аудит.

* **Безопасность сети зависит от числа майнеров.** Пока майнеров мало, любой, у кого мощность больше остальных, может
  переписывать недавние блоки (атака 51%). Не считайте переводы окончательными, пока нет хотя бы десятка подтверждений.
* **Майнер на Python медленный.** Для серьёзной сети нужен майнер на C/GPU: протокол у него тот же, а `core.py`
  остаётся образцом правил. Вместе с ростом мощности сложность вырастет сама.
* **Нет шифрования и аутентификации между узлами** (обычный HTTP), нет защиты от целенаправленной DDoS-атаки: ставьте
  узел за обратным прокси. Есть ограничение частоты запросов, лимиты размеров, защита от обращения узла к внутренним адресам.
* **Файл кошелька шифруется паролем** (scrypt + HMAC-SHA256, только стандартная библиотека). Схема самописная и не проходила внешний аудит: храните файл на зашифрованном диске. Вместо seed-фразы из 24 слов используется код восстановления с контрольной суммой: любая опечатка ловится. Стандарт BIP39 можно добавить, если подключить его словарь.
* **Масштаб.** Цепочка хранится файлом (по блоку на строку) и при запуске проверяется целиком. Для сотен тысяч блоков
  потребуется база данных и снимки состояния. При реорганизации за один раз принимается ветка до 5 000 блоков.
* **Нет контрольных точек**: узел, который впервые скачивает цепочку, верит ветке с наибольшей работой.
* **Один ключ у основателя**: его кража означает потерю уже размороженной части. Мультиподписи в сети нет.
* Эта программа **не биржа**. Торговля монетой это отдельный вопрос: лицензирование, KYC/AML и ответственность за
  чужие деньги. В Армении виртуальные активы регулирует Центральный банк; актуальные требования проверьте у юриста до
  публичного запуска и продаж. Это не юридическая консультация.
* Цену монете задают сделки независимых людей. Не обещайте доход и не называйте «цену» монеты: опишите проект,
  токеномику (90% майнерам, 10% основателю с заморозкой на 2 года) и риски.
